# ShadowFire — TrustHire Frontend

A polished frontend prototype for the TrustHire job-offer checker, built from `TrustHire_PRD.md`.

## Run locally

```bash
npm install
npm run dev
```

## Scope

This repository intentionally contains only the frontend. Scan analysis and history are local demo behaviours; no database, OCR, API, or authentication service is connected. See [`specs/spec.md`](specs/spec.md) for requirement traceability and intended integration points.
