# TrustHire frontend principles

1. Use advisory language. The interface assesses an offer's signals; it never declares a company or person fraudulent.
2. Explain every risk signal in plain language and include the evidence used.
3. Respect privacy by default. The frontend-only prototype stores no uploads and uses browser-local history only.
4. Keep scoring deterministic in the UI prototype so each result is reproducible for the same input.
5. Make the product accessible: keyboard controls, labels, readable contrast, and no colour-only risk communication.
